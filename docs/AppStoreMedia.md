# CycleWrench App Store media

Prepared October 27, 2026 from Apple's current [asset best practices](https://developer.apple.com/app-store/asset-best-practices/).

## Delivered assets

| Asset | File(s) | Specification / purpose |
|---|---|---|
| App icon | `AppStore/Icon/CycleWrench-1024.png` | 1024×1024 opaque RGB PNG, square canvas; iOS applies its own mask |
| Native launch screen | `AppStore/Launch/LaunchScreen.storyboard` | Adaptive grouped background, light/dark and orientation aware, no text/logo/delay |
| iPhone screenshots | `AppStore/Screenshots/iPhone/01-home.png` through `04-custom-components.png` | 1206×2622 opaque PNG, Dynamic Island medium display |
| iPad screenshots | `AppStore/Screenshots/iPad/01-home.png` through `04-custom-components.png` | 2064×2752 opaque PNG, iPad 13-inch display |
| Capture data | `AppStore/Capture/TestBike.json` | Synthetic **Test bike** only, with demonstration dates and odometers |
| Generation record | `AppStore/Icon/Prompt.md` | Final icon prompt, tool and size normalization details |

The icon uses a white pedal-bicycle/wrench mark against cobalt blue. Large rounded
strokes and a restrained two-color treatment keep it recognizable at Home Screen
and search sizes. The icon master has no outer rounded corners or transparency.
It was made with the built-in image generation tool; it is not an Icon Composer
layered document. Layered, dark and tinted artwork can be considered separately.

## Screenshot sequence

1. **Home:** bike choice, direct odometer update, Components and Service history
   navigation, and the compact maintenance form.
2. **Components:** personal average lifespan, completed-interval count, distance
   since work, and remaining distance sorted by earliest attention.
3. **Service history:** the real dated maintenance list.
4. **Custom components:** name, default action and optional independent front/rear
   tracking in the actual creation screen.

These are full, unaltered app screenshots captured through XCUITest. They contain
no generated interface, device frame, invented state, unverified integration
claims, awards, pricing, URLs or personal rider data. The design-only app target
uses the production SwiftUI source, with the CycleWrench display name, on dedicated
simulators. No Orbea Wild store was opened or modified by the capture process.

Capture used separate bundle ID `com.cyclewrench.design` and a separate build
folder under ignored `work/design/`, avoiding the main app's installation and
parent agent's build/test directory. UI navigation captures passed on both device
families. Original XCUITest attachments and capture harness remain in ignored
`work/design/`; only the final media and synthetic fixture are included here.

## Launch screen, not a branded splash

Apple recommends a launch screen that resembles the initial UI and avoids logos
or fixed text. CycleWrench should reach the maintenance form immediately, so the
handoff is an adaptive `systemGroupedBackgroundColor` storyboard. It intentionally
adds no extra splash screen or timed animation. See [Apple's launching guidance](https://developer.apple.com/design/human-interface-guidelines/launching).

The launch resource is integrated at `CycleWrench/LaunchScreen.storyboard` and
`project.yml` sets `UILaunchStoryboardName` to `LaunchScreen`, replacing the
autogenerated launch-screen configuration. The AppStore copy remains the design
handoff/source of record.

## Required versus optional App Store media

Apple currently requires at least one screenshot in each required device slot:
Dynamic Island medium iPhone, plus 13-inch iPad because this app supports iPadOS.
The delivered portrait sizes are accepted for those slots; up to ten screenshots
per size can be uploaded. All delivered PNGs are opaque. See [current screenshot
specifications](https://developer.apple.com/help/app-store-connect/reference/app-information/screenshot-specifications).

App previews (video), product-page headers, search-result creative assets and
in-app-event media are optional for the initial submission; no event or video is
invented here. If added later, Apple's [creative asset specifications](https://developer.apple.com/help/app-store-connect/reference/app-information/creative-assets-specifications)
currently list a 3840×1646 header and 1920×1280–3840×2560 search image option, plus
other accepted formats. Recheck specs when producing those assets.

Apple's current screenshot page also notes a future iPhone Duo requirement from
April 2027 for submissions using the iOS 27.1 SDK or later. Those screenshots are
not required for the current October 2026 handoff; revisit before a later release.
