# Launch screen design

`LaunchScreen.storyboard` fills the screen with adaptive
`systemGroupedBackgroundColor`. It has no text, logo, artificial delay, or layout
that could flash against the native Form UI. The same resource supports light,
dark, portrait and landscape appearances.

This is intentionally a launch screen, not a branded splash or onboarding screen.
CycleWrench's core interaction should be available immediately. No separate
splash bitmap is needed or recommended.

Integrated at `CycleWrench/LaunchScreen.storyboard`. `project.yml` sets
`UILaunchStoryboardName` to `LaunchScreen` and removes the autogenerated
`UILaunchScreen` configuration to avoid defining two launch mechanisms.

[Apple launch guidance](https://developer.apple.com/design/human-interface-guidelines/launching)
