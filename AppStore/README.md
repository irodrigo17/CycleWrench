# CycleWrench App Store media

- `Icon/CycleWrench-1024.png`: selected sculpted cream/forest/copper MTB icon, opaque 1024×1024.
- `Launch/LaunchScreen.storyboard`: native adaptive launch screen handoff.
- `Screenshots/iPhone/`: real app captures at 1206×2622 pixels.
- `Screenshots/iPad/`: real app captures at 2064×2752 pixels.
- `Capture/TestBike.json`: synthetic-only data used for every screenshot.

The screenshot sequence is home/logging → component lifetimes → maintenance
history → custom components. These are unaltered screenshots of the actual app,
not generated UI or claims about unverified iCloud/Bosch integrations.

See [the media manifest](../docs/AppStoreMedia.md) for capture details, integration
and current Apple specifications. Do not substitute personal rider data in media.
