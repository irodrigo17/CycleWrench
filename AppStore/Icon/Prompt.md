# Active CycleWrench icon

The active master is `CycleWrench-1024.png`, identical to the chosen
`CycleWrench-MTB-1024.png` proposal. It uses a sculpted full-suspension bicycle,
copper wrench, forest-green tires and background, cream frame, and warm light.

See [the refinement prompt](MTB-Refinement-Prompt.md) for the generation record.
The earlier blue design and its prompt are archived under `Variants/`.

The master is an opaque RGB 1024×1024 PNG with a square full-bleed canvas.
The app asset catalog uses the same bytes; iOS applies the icon mask.
